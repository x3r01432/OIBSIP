# Java Development — Task 2: Number Guessing Game

Console game where the computer picks a random number and the player guesses with hints.

## Features
- Random number generated each round
- Guess prompt via `Scanner`
- "Too High!" / "Too Low!" / "Correct!" feedback
- Visible attempt counter
- Max attempts limit → "You Lost!" reveals the number
- Play Again prompt and multi-round "Round X — guessed in Y attempts" summary
- Bonus: difficulty levels (Easy/Medium/Hard)

## Tech Stack
Java (console), `java.util.Random`, `Scanner`.

## Run
```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
