# WebDev Level 1 — Task 2: Personal Portfolio

A responsive single-page portfolio / digital résumé for Steven Manuel Rios.

## Features
- Hero section: name, role title, avatar placeholder
- About Me section (background + interests)
- Skills section: visual grid of technical skills
- Projects section: 2 project cards (title, description, GitHub link placeholder)
- Contact section: name, email, LinkedIn/GitHub links
- Smooth scroll navigation (`scroll-behavior:smooth`)
- Consistent dark branding (colour scheme + font family)
- Fully responsive (desktop + mobile)

## Tech Stack
HTML5, CSS3.

## Run
Open `index.html` in a browser.
