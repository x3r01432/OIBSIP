# WebDev Level 2 — Task 2: Tribute Page

A tribute page for **Ada Lovelace**, the first computer programmer.

## Features
- Page title with name + one-line tagline
- Prominent portrait image (Wikimedia Commons, public domain) with graceful fallback
- Biography: 4 paragraphs of original paraphrased content
- Key achievements timeline (styled list)
- Distinctly styled quote block
- Two background colours across sections; serif headings/body + sans-serif accents (2 font styles)
- Responsive layout

## Tech Stack
HTML5, CSS3.

## Run
Open `index.html` (image loads from Wikimedia; page still works offline).
