# WebDev Level 2 — Task 3: To-Do Web App

Interactive task manager with pending/completed lists.

## Features
- Input + "Add Task" button; new tasks appear immediately in Pending
- Mark Complete toggle moves tasks to Completed (and back)
- Inline Edit (via prompt) and permanent Delete
- Count indicators: "X pending" / "Y completed"
- Timestamps for added and completed times (bonus)
- Persistence across refreshes via localStorage (bonus)
- Friendly empty-state messages

## Tech Stack
HTML5, CSS3, Vanilla JavaScript (localStorage).

## Run
Open `index.html`.
