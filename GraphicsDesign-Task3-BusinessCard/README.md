# Graphics Design · Task 3 — Business Card

A print-ready, double-sided business card for **Verdant**, built on the Task 2 logo system.

## Deliverables
- `business_card_print_ready.pdf` — **2 pages** (front + back), 300 DPI, with 3 mm bleed.
- `card_front_with_bleed.png` / `card_back_with_bleed.png` — 300 DPI raster proofs.
