# WebDev Level 1 — Task 3: Temperature Converter

Interactive web tool converting between Celsius, Fahrenheit and Kelvin with validation.

## Features
- Numeric input with validation (rejects non-numeric with an error message)
- Unit selector dropdown (C / F / K)
- Auto-conversion showing all output units simultaneously
- Convert button triggers calculation on click
- Result area with labelled units
- Absolute-zero edge case handling (rejects below -273.15°C)
- Clean centred UI

## Tech Stack
HTML5, CSS3, Vanilla JavaScript.

## Run
Open `index.html` in a browser.
