# Data Science — Task 2: Unemployment Analysis with Python
Notebook: `unemployment_analysis.ipynb` (executed, with outputs)

- Data: *Unemployment in India* (CMIE, monthly by state, Jan–Oct 2020), from the public Kaggle dataset; a copy is in `data/`
- Cleaning: stripped headers, date parsing, renamed columns, null check
- Region (zone) averages, month-wise trend, time series for 5 major states, top-10 states bar chart, correlation heatmap
- Pre-COVID (Jan–Mar) vs post-COVID (Apr–Oct) comparison, overall and per state
- **Key finding:** the average rate rose from ≈9.8% to ≈13.3%, peaking at ≈23% in May 2020, and recovered to ≈8% by October
