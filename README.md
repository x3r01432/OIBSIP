### Notes
- Each folder's own `README.md` documents its build/run steps, tests, and outputs.
- Where a GUI/device was required but unavailable in a headless build environment (e.g., the Android emulator, GUI screenshots for security tools), this is stated in that task's README and the equivalent evidence (build logs, unit-test results, verbatim tool output) is included instead.
- Security Analyst tasks were performed exclusively against local, self-owned targets.
