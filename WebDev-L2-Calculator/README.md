# WebDev Level 2 — Task 1: Calculator

A browser-based calculator with a button grid UI.

## Features
- Display screen showing input and result
- Number buttons 0–9 and decimal point
- Operators + − × ÷
- Equals (=) to evaluate; Clear (C) to reset; Backspace (⌫)
- Division-by-zero shows an error instead of crashing
- Operator chaining (sequential operations)
- CSS Grid button layout
- Event listeners (no inline onclick); custom logic (no `eval()`)

## Tech Stack
HTML5, CSS3, Vanilla JavaScript.

## Run
Open `index.html`.
