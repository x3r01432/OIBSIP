# WebDev Level 1 — Task 1: Landing Page

A static, responsive landing page for a fictional coffee brand, **NovaBrew**.

## Features
- Sticky navigation bar with 3 links (Features, About, Testimonials)
- Hero section with headline, subheadline, and CTA button
- Three content sections: Features, About, Testimonials
- Footer with placeholder contact/social links
- Consistent brown/gold colour palette via CSS variables
- Responsive layout using CSS Grid + Flexbox (no breakage at mobile widths)
- Intentional box-sizing, padding, margins (no overlap)
- Typography hierarchy (heading vs body sizes)

## Tech Stack
HTML5, CSS3 (no JavaScript).

## Run
Open `index.html` in any browser.
