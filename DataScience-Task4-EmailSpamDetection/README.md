# Data Science — Task 4: Email Spam Detection
Notebook: `spam_detection.ipynb` (executed, with outputs)

- Data: **SMS Spam Collection**, UCI ML Repository (5,572 messages; 13.4% spam), in `data/`
- Preprocessing: lowercase, URL/number/punctuation removal, stop-words, Porter stemming (NLTK)
- TF-IDF (unigrams + bigrams), with an explanation of what TF-IDF measures
- Multinomial Naive Bayes, Logistic Regression, Linear SVM: accuracy, precision, recall, F1, confusion matrices
- Discussion of why recall matters; bonus spam/ham word clouds
- **Best balance:** Linear SVM, F1 ≈ 0.946 (precision 0.946, recall 0.946)
