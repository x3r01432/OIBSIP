# Python Programming — Task 2: BMI Calculator

Both tiers implemented.

| Tier | File | Features |
|---|---|---|
| Beginner | `bmi_cli.py` | CLI prompts, BMI = w/h², category classification, 2-dp output, validation of non-numeric/negative input |
| Advanced | `bmi_gui.py` | tkinter GUI, colour-coded result, multi-user records in SQLite (`bmi_history.db`), matplotlib trend chart, DB error handling |

## Run
```bash
python bmi_cli.py
pip install matplotlib && python bmi_gui.py
```
